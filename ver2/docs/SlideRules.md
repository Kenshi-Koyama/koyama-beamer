# 発表スライド作成ルール v2（Quarto → Beamer、16:9）

> v2（`koyama2-beamer`）でスライドを作るときのデザインのルール。v1（4:3）のルールは [../../ver1/docs/SlideRules.md](../../ver1/docs/SlideRules.md)。
> 出力は **Quarto → Beamer PDF**（lualatex / metropolis を土台に作り直したデザイン / Noto Sans + Noto Sans JP、16:9）。
> 実装（色・部品の定義）は `_extensions/koyama2/beamer-preamble.tex`、使い方の実例は `template.qmd`。
> 応用（色の差し替え・著者・付録など）は [recipes.md](recipes.md)、作る順番は v1 と共通の [workflow.md](../../docs/workflow.md)。

---

## 0. 基本方針（1行で）

**「1枚 = 1メッセージ」**。リード文・箇条書き・`⇒` の結論は、そのスライドに必要なときだけ使う
（図や表だけのスライドがあってもよい）。
白地に、ティール（構造）とコーラル赤（強調）の2色で組む。帯やナビバーは置かず、余白を惜しまない。

---

## 1. カラーパレット

色は**役割の名前**で呼ぶ。下の「既定の色」は研究ごとに変えてよい（YAML の `palette:`。[recipes.md](recipes.md) の 7.）。
名前と役割はそのままなので、色を差し替えてもこのページのルールはそのまま使える。

| 色名 | 既定の色（RGB） | 役割 |
|---|---|---|
| `textmain` | 黒に近い灰（34,34,34） | 本文・タイトル・`Table X:`/`Figure X:` のラベル |
| `textmuted` | 青みの灰（108,117,128） | 出典 `(Author, Year)`・`Note:` |
| `textlight` | 灰（150,150,150） | 右上のセクション名・ページ番号・○● |
| `textfaint` | 薄い灰（190,190,190） | 目次の、今のセクション以外の名前 |
| `background` | 白 | 背景 |
| **`primary`** | ティール（69,176,176） | **構造**：番号の四角・箇条書きの記号・目次の線・`tagbox[primary]` の枠。**文中の強調**にも使う |
| `primarylight` | `primary` の 20% | 変数定義ボックス（`defbox`）の地 |
| `primarymid` | `primary` の 45%（自動） | 番号の四角の影 |
| **`accent`** | コーラル赤（237,80,87） | **文中の強調**・対比の一方・`tagbox`（Research Gap など）と `keytakeaway` の枠 |
| `accentlight` | `accent` の 28% | alert ブロックの地（ふだんは使わない） |
| **`highlight`** | 橙（232,155,0） | 表の注目セル（`\cellcolor{highlight!25}`）・表の値の枠（`\ybox`）・**3つ目の区分** |

### 色の使い方
1. **`primary` と `accent` で文中の語を強調する**。2つの群・概念の対比は `primary ↔ accent` で表す
   （例：`\textcolor{primary}{軽症}` vs `\textcolor{accent}{重症}`）。図でも同じ割り当てにそろえる。
2. **1枚あたりの強調は絞る**：文中の色の強調は合計で原則2〜3語まで。
3. **区分が3つあるとき**（例：軽症・中等症・重症）は、3つ目に `highlight` を使ってよい。
   このときだけ `highlight` を文字色にしてよい（区分の名前など、短い太字の語に限る）。
4. **白地とのコントラストは低め**（`primary` 約 2.6:1、`accent` 約 3.6:1、`highlight` 約 2.3:1。WCAG の本文基準 4.5:1 を下回る）。
   色を付けるのは短い語・見出し・数字だけにし、文章まるごとを色文字にしない。
   投影環境が明るい・暗いときは、`palette:` で濃い色に差し替える。

### 書き方
- 文中の強調：`\textcolor{accent}{...}` / `\textcolor{primary}{...}`（`\alert` は使わない。v1 と同じ）
- 表のセル背景：`\cellcolor{highlight!25}セル内容`
- 文中の語句の下に斜線を引く：`\hatch{...}`（`accent`）/ `\hatch[primary]{...}`（2. を参照）

## 2. レイアウトと情報量

### 1枚の構成
- **左上**：セクション番号の四角（ティール、右下に淡い影）と、黒字のスライドのタイトル。
  - 四角の番号は本編が `01, 02 …`、付録が `A1, A2 …`（9. を参照）。
  - References のスライドは四角だけ（番号なし）。
- **右上**：グレーのセクション名と、その下に ○●（そのセクションの何枚目か。● が今のスライド）。右端にページ番号。
- 本文はタイトルのすぐ下から上詰めで書く。下は空いてよい。

### よく使う型（必須ではない。スライドの役割に合わせて選ぶ）
1. 上部の中央に**リード文1行**（そのスライドの主張）：`\leadline{...}`。
   要点の語に `\hatch{...}` で斜線を引いてよい（1行に1〜2か所）。
2. 流れを見せるときは、間に `\flowdown`（▼）を置く（前提 ▼ 結論、問題 ▼ 既存研究、など）。
3. その根拠・詳細を箇条書き（3. を参照）。
4. 最下部に `⇒` で**結論/含意を1行**。
   一番覚えてほしい一文は、`keytakeaway`（赤い枠・中央ぞろえ）で格上げしてよい（1デッキで数回まで）。

- 数式は**原則1枚1本**（IV のように第1・第2段階を並べるときは2本まで）。
- **スライドのタイトルは黒字だけ**。色・強調を使わない（v1 と同じ）。
- タイトルは1行に収める（2行になると右上の表示と近づく）。目安は全角で 25 字前後まで。

### 表紙
YAML から自動で組む（[recipes.md](recipes.md) の 4.・10.）。
右上に学会名（`event:`）とティール→赤のグラデーションの帯、その下に `日付@会場`（`date:`・`venue:`）。
中央にタイトル、淡いティールの線、その下に著者の名前と所属を横に並べる（発表者に `*`）。
最下部に本編のセクションを左から並べ、セクション名と、その下にスライドの数だけの ○ を置く。
各セクションの欄の上端に細い淡いティールの線（両端を少し詰めて、線の本数でセクションの数も見せる）。
欄の幅は名前の長さに合わせて変わる（名前と ○ の列の長い方に、余った幅を各欄へ等しく足す）ので、長い名前でも重ならない。
名前の合計が長すぎると収まらないので、セクション名は短めにする
（v1 の上部のナビバーと同じ形）。最初のスライドで、全体の構成と枚数の目安が分かる。

## 3. 箇条書き（階層ルール）

| 階層 | 記号 | 用途 |
|---|---|---|
| 見出し | なし（太字・左端） | まとめのカテゴリ（**Research Question**・**Data**・**Findings** など） |
| L1 | ティールの小さい ● | 主要な論点 |
| L2 | ティールの短い横線 `-` | L1 の具体・補足 |
| L3 | ティールの短い横線 `-` | さらに細分 |

- **まとめのカテゴリには ● を付けない**。Markdown で `- **Data**` と書き、その下に子の箇条書きを置けば、
  テンプレートが自動で「太字の見出し（左端）＋子を1段目の箇条書き」にする。2つ目以降の見出しの前には空きが入る。
  `defbox` の中でも同じ（`::: defbox` で囲めば Markdown で書ける。5. を参照）。
- **論理展開は `→`、結論・帰結は `⇒`**。矢印で始める項目には ● を付けない
  （`- $\to$ …` や `- → …` と書けば、● の位置に矢印が入る）。
- 1つの見出しの下は **2〜4項目**が目安。5項目を超えるならスライドを割る。
- まとめのスライドは「**Findings** / **Policy Implications**」の2つの見出しを標準にする。

## 4. 左右2カラム（`columns`）

- **左＝視覚物（図・表・数式）、右＝解釈の言葉**、を基本形にする。
- 16:9 の本文の幅は約 137mm（5.41 インチ）。右カラムを 42% にすると、日本語は1行に約 14 字。
- **幅は決め打ちしない**。図をなるべく大きく見せつつ、右の文字が細切れに折り返さない幅を探す。
- 右カラムでは、大きな数字（例：`{\fontsize{22}{26}\selectfont\textcolor{primary}{47\%}}`）と `\flowdown`、
  `\hatch` を組み合わせて「数字 ▼ 帰結」を見せてもよい（`template.qmd` の 3 枚目）。

## 5. 数式と囲み

- **数式を上部**に置き、右端に式番号。
- 変数定義は `defbox`（淡いティールの地）で囲む。中は「カテゴリの見出し（● なし）＋変数の定義」：

```markdown
::: defbox
-   **Outcome variable**
    -   $Y_{it}$：アウトカム（単位）
-   **Main explanatory variables**
    -   $D_{it}$：処置の変数。基準は\textcolor{accent}{参照カテゴリ}
:::
```

- 囲みは次の4種類だけ。普通の箇条書きを囲まない。入れ子にしない。

| 部品 | 見た目 | 使う場面 |
|---|---|---|
| `defbox` | 淡いティールの地・枠なし | 数式の変数定義 |
| `tagbox` | 角の丸い枠＋左上に丸いラベル、中は太字・中央ぞろえ | Research Question / Research Gap など、問いを1〜2行で示す |
| `keytakeaway` | 赤い枠・太字・中央ぞろえ・少し大きい | 核心の一文（1デッキで数回まで） |
| `bluebox` | ティールの細い枠 | 補足（ふだんは使わない） |

```latex
\begin{tagbox}{Research Gap} … \end{tagbox}               % 赤（既定）
\begin{tagbox}[primary]{Research Question} … \end{tagbox} % ティール
\begin{keytakeaway} … \end{keytakeaway}
```

- 区分ごとの値を横に並べるときは `\cardbox[色]{区分\\値}`（角の丸い色枠）を使ってよい
  （`\leadline{\cardbox[primary]{…}\hspace{6mm}\cardbox[highlight]{…}}`）。

## 6. 表（Table）

v1 と同じ。

- **縦罫線なし・横罫線のみ**（`booktabs`）。
- ラベル `Table X:` は**黒の太字**（`\tlabel{Table 1:}`）、表の**上**に置く。
- 注目セルは `highlight` の背景（`\cellcolor{highlight!25}`）か、値を `\ybox{...}` で囲む（1表 1〜2 か所まで）。
- 区分の列見出しは、図と同じ色の文字にしてよい（`\textcolor{primary}{区分1}` など）。
- 表の下に `Note:`（`\slidenote{...}`）や有意水準（`\tinynote{...}`）。
- 強調の不要な表は Markdown のパイプテーブルで書いてよい。
- 分析コードから表を出すときは `tabular` だけの断片を書き出し、`\begin{center}\small\input{…}\end{center}` で貼る。

## 7. 図（Figure）

### 方針：図はなるべく大きく見せる

v1 と同じ。リード文をやめて主張をタイトルに書く、2カラムをやめて中央1枚にする、
図の縦横比を空いている高さに合わせて作り直す、などで図を大きくする。

### 図の作り方（実寸で作る。16:9 で測った値）

- 本文の幅 ≈ **5.4 インチ**（用紙 160mm − 左右の余白 11.3mm × 2）。図は 300dpi の PNG で作り、
  `\includegraphics[width=\linewidth]{…}` で等倍に貼る。
- 高さの目安（中央1枚・幅 5.4 インチ）：
  - タイトル＋図＋キャプションと注（2行）→ **約 1.9 インチ**まで（2.0 インチで注の2行目が切れた）
  - タイトル＋リード1行＋図＋キャプションと注（2行）→ **約 1.6 インチ**まで（1.7 インチで切れた）
- 16:9 は横長なので、幅いっぱいの図はかなり平たくなる（5.4 × 1.9 インチ）。
  縦に高さが欲しい図は、幅を 3.5〜4 インチ程度にして中央に置くか、2カラムで右に解釈を並べる。
- 文字：フォントはスライドと同じ（日本語 Noto Sans JP、欧文 Noto Sans）、軸 8.5pt・凡例 9pt。
- 図の中にタイトル・注は入れない（スライドのタイトル・リード文と `Note:` 行に書く）。
- 群は色だけに頼らず形も変える。色はスライドと同じ割り当て（`primary`・`accent`・`highlight`）。
- 新しい図は、テスト用のデッキで実寸に貼って、はみ出し・文字の大きさを目で確認してから本番に使う。

### その他

- ラベル `Figure X:` は**黒の太字**（`\tlabel{Figure 1:}`）、図の**下**に置く。出典は `\slidenote{(source: …)}`。
- 図がまだ無いときは `\figplaceholder[幅]{ファイル名}` で仮置きする。
- 決定木・DAG は tikz（`box_node`＝ティールの枠、`key_node`＝赤の枠（結論の1ノードだけ）、`dag_node`、`arrow`）。

## 8. 引用・出典

v1 と同じ。

- 本文引用は `(Author, Year)`、`textmuted` の小さめ。箇条書きの項目ごとの出典は `\srcite{key}`。
- 参考文献は APA（`biblatex` + biber）。末尾に `## References {.allowframebreaks}` と `\printbibliography[heading=none]`。
  文字は 7pt・行送り 8.4pt。
- `.bib` の題名の固有名詞は `{}` で囲む（APA は題名を小文字化するため）。

## 9. ナビゲーション・全体構成

- **ナビバーは無い**。今どこにいるかは、右上のセクション名と ○● で示す。
- **全体の構成**は、表紙の最下部の帯で見せる（セクション名とスライドの数だけの ○）。
- **2つ目以降の各セクションの冒頭に目次**を自動で入れる（「次にどこへ行くか」を示す）。
  最初のセクションの前には入れない（ほとんど話すことのないスライドで、大事な2枚目を使わないため）。
  左上にデッキの短いタイトル（`shorttitle:`）、今のセクションは濃い四角＋黒字、ほかは淡い四角＋薄いグレー。
  - 短い発表（15〜20分）では YAML に `section-outline: false` を書いて目次を入れない（表紙の帯は出る）。
- **References のスライド**は、四角に番号を書かず、右上のセクション名と ○● も出さない
  （`\printbibliography` のあるスライドをテンプレートが自動で見つける）。そのセクションの ○● にも数えない。
- **付録**：References の下に `\appendix` を書き、そのあとを `#` のセクションで始める（[recipes.md](recipes.md) の 9.）。
  - 四角の番号は `A1, A2 …`、右上はそのセクションの名前と、付録のセクションの中での ○●。
  - 付録のセクションは目次に載らず、付録の前に目次スライドも入らない。
  - ページ番号は付録で 1 から数え直す（本編の総ページ数に含めない。v1 と同じ）。
- 付録へのジャンプは `\hyperlink{ラベル}{\beamerbutton{…}}`、飛び先に `\hypertarget{ラベル}{}`。

## 10. フォント

v1 と同じフォント（欧文の本文だけ Regular → Medium）。

| 文字 | 本文 | 太字 |
|---|---|---|
| 日本語 | Noto Sans JP Medium | Noto Sans JP SemiBold |
| 欧文・数字 | Noto Sans Medium | Noto Sans Bold |
| 等幅 | Noto Sans Mono Medium | — |
| 数式 | Latin Modern Math | — |

- 本文は通常の太さ。スライドのタイトル・表紙・目次・右上の表示・箇条書きの見出し・
  `tagbox` と `keytakeaway` の中身は太字。

## 11. やってはいけない（チェックリスト）

- [ ] 色を増やしすぎない（`primary`＋`accent`、区分が3つのときだけ `highlight`。新しい色を足さない）。
- [ ] 文章まるごとを色文字にしている → 色は短い語・数字だけ。
- [ ] 囲みを多用・入れ子にしている（`defbox`・`tagbox`・`keytakeaway`・`bluebox` の4種類だけ）。
- [ ] スライドのタイトルに色・強調を使っている → 黒字だけにする。
- [ ] まとめのカテゴリ（Research Question・Data・Findings など）に ● が付いている → `- **見出し**` の下に子を置く。
- [ ] 「● →」と記号が2つ並んでいる → 矢印の項目には ● を付けない。
- [ ] `\hatch` を1行に3か所以上 → 効かないので1〜2か所に絞る。
- [ ] 文中の強調が1枚に4語以上 → 削る。
- [ ] 1枚に数式2本以上（IV 例外を除く）→ スライドを割る。
- [ ] 図の歪み・出典漏れ・`Table/Figure` ラベル漏れ・図が小さい（7.）。
- [ ] 下にはみ出している（16:9 は縦が短い。7. の高さの目安を見る）。
- [ ] `\appendix` のあとを `#` で始めていない → 付録の番号（A1）が付かない。
- [ ] `\alert` を使っている → `\textcolor{accent}{...}` にする。

## 12. 設計意図 → 実装 早見表

| 見た目 | 実装 |
|---|---|
| 左上の番号の四角・タイトル | `frametitle` テンプレート（自動） |
| 右上のセクション名・○●・ページ番号 | `headline` テンプレート（自動。○● の枚数は前回のコンパイルで数える） |
| 2つ目以降のセクション冒頭の目次 | 自動（`section-outline: false` で消す） |
| 表紙 | YAML の `title`・`author`（`affiliation`・`presenter`）・`event`・`venue`・`date` |
| 表紙の最下部の帯（セクション名と ○） | 自動（枚数は前回のコンパイルで数える） |
| 文中の強調 | `\textcolor{accent}{...}` / `\textcolor{primary}{...}` |
| 語句の下の斜線 | `\hatch{...}` / `\hatch[primary]{...}` |
| 中央ぞろえの1行 | `\leadline{...}` |
| 流れの ▼ | `\flowdown` |
| カテゴリの見出し（● なし） | `- **見出し**` の下に子の箇条書き（自動） |
| 矢印の項目（● なし） | `- $\to$ …` / `- → …`（自動） |
| 変数定義ボックス | `::: defbox … :::` または `\begin{defbox}` |
| 問いの枠（ラベル付き） | `\begin{tagbox}[色]{ラベル} … \end{tagbox}` |
| 核心の一文 | `\begin{keytakeaway} … \end{keytakeaway}` |
| 値のカード | `\cardbox[色]{区分\\値}` |
| 表の注目セル・値 | `\cellcolor{highlight!25}` / `\ybox{...}` |
| Table/Figure ラベル | `\tlabel{Table X:}` |
| 図表の注・出典 | `\slidenote{...}` / `\tinynote{...}` / `\srcite{key}` |
| 図の仮置き | `\figplaceholder[幅]{ファイル名}` |
| 付録 | `\appendix` のあとを `#` で始める |
| パレットの差し替え | YAML の `palette:` |
