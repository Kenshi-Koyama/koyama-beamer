# 発表スライド作成ルール（Quarto → Beamer）

> このテンプレート（`econ-beamer`）でスライドを作るときのデザインのルール。
> 出力は **Quarto → Beamer PDF**（lualatex / metropolis + miniframes / Noto Sans + Noto Sans JP、4:3）。
> 各ルールの実装（色・部品の定義）は `_extensions/econ/beamer-preamble.tex`、使い方の実例は `template.qmd`。

---

## 0. 基本方針（1行で）

**「1枚 = 1メッセージ」**。上部に太字リード → 根拠を箇条書き → 最下部に `⇒`/`→` で結論。
色は「構造」と「強調」を厳密に役割分担し、余白を惜しまない。

---

## 1. カラーパレット（この設計の核心）

| 色名 | RGB | 役割（この1点に限定して使う） |
|---|---|---|
| `textblack` | 42,46,51 | 基本テキスト |
| `textgray` | 141,142,143 | 出典 `(Author, Year)`・`Note:`・非アクティブなナビ |
| `bgwhite` | 255,255,255 | 背景（原則ベタ塗りしない） |
| **`mainblue`** | 54,136,214 | **構造の主役**：箇条書きL1の●／`Table X:`・`Figure X:`ラベル／ブロックタイトル／セクションナビ／付録ボタン。**文中キーワード強調**にも使ってよい |
| `midblue`（`mainblue!35!white` で自動生成） | 約185,213,241 | ブロック本文の地色／ナビバーの地色 |
| `subblue` | 227,241,255 | frametitle帯の地色／**数式の変数定義ボックスの地色** |
| **`mainred`** | 210,48,55 | **文中キーワード強調**／対比の一方（例：処置群 vs 対照群の片側）。白背景コントラスト比 約5.0:1（WCAG AA本文基準クリア） |
| `subred` | 249,183,185 | alertブロック本文の地色 |
| **`mainorange`** | 240,199,74 | 表・数値の「枠／セル背景」ハイライト（"ここを見て"）専用。**文字色には絶対に使わない**（白背景コントラスト比 約1.6:1しかなく、プロジェクター投影では特に読めない） |

### 色の3原則
1. **blue＝構造＋文中キーワード強調、red＝文中キーワード強調・対比の一方、orange＝データの注目点**。
   blueは箇条書き点・ラベル・帯などの「構造」用途に加え、**対比相手が無い単独の文中強調**にも使ってよい
   （例：その回の主役概念1つだけを青で強調）。ただし多用すると構造色との区別が曖昧になるので、
   1枚のうち「構造としてのblue」と「強調としてのblue」を同時に多用しすぎない。
2. **1枚あたりの強調は絞る**：文中の `red`/`blue` 強調は合計で原則2〜3語まで、`orange` ハイライトは表の中の1〜2箇所まで。
3. **対比（2グループ）** は `blue ↔ red` の文字色で表す（例：`\textcolor{mainblue}{対照群}` vs `\textcolor{mainred}{処置群}`）。赤枠 vs 青枠の二色対比は導入せず、代わりに**表内の注目セルは `orange` の枠/背景**で示す。
   図でも同じ割り当て（処置 = red、対照 = blue）にそろえる。

### 実装メモ
- 文中強調：`\textcolor{mainred}{...}` / `\textcolor{mainblue}{...}` を直接使う（太字併用は`\textcolor{mainred}{\textbf{...}}`）。
  `\alert{...}`はbeamerの`alerted text`色（=mainred）しか使えずblueに対応できないため、
  red/blue共通の書き方として`\textcolor`に統一する（**`\alert` は使わない**）。
- 表のセル背景：`\cellcolor{mainorange!25}セル内容`（`colortbl` はプリアンブルで読み込み済み）。
- 表の値やまとまった文章を「枠」で囲む：短い語句は `\ybox{...}`、複数行の文章は `keytakeaway` 環境。

## 2. レイアウトと情報量

- **1枚1メッセージ**。詰め込まない。行間・段落間の余白（`\vspace`）を積極的に取る。
- **構成の型**：
  1. 上部に**太字のリード文1〜2行**（そのスライドの主張）。※必ずしも●を付けない見出し文でよい。
  2. その根拠・詳細を箇条書き（最大3階層）。
  3. 最下部に `⇒` または `→` で**結論/含意を1行**（必要なとき）。
     そのスライドで一番覚えてほしい核心の一文（議論の転換点・研究の新規性など）は、
     矢印の代わりに `keytakeaway` 環境（オレンジ枠）で視覚的に格上げしてよい。
     ただし多用すると効果が薄れるので、1デッキで数回程度・本当に格上げしたい一文だけに絞る。
- 数式は**原則1枚1本**（IVのように第1・第2段階を並べるときは例外的に2本まで）。
- frametitleは `subblue` の帯。表紙と目次にはタイトル帯を付けない。
- 発表者オリジナルの意見・構成のスライド（論文の要約ではなく自分の見解）は、見出し自体を `\textcolor{mainred}{...}` で色付けして区別する。
  - 注意: `\setbeamercolor{frametitle}{...}` を `##` 見出し間の生LaTeXブロックで切り替える方式は、pandocがそのブロックを「前フレームの本文末尾」に配置し、かつbeamerの`frame`環境が内部でグループ化されているため機能しない。見出しテキスト自体を色付けする方式を使うこと。

---

## 3. 箇条書き（階層ルール）

| 階層 | 記号／色 | 用途 |
|---|---|---|
| L1 | blue ●（見出しは**太字**） | 主要な論点の見出し |
| L2 | blue ●（小） | L1の具体・補足 |
| L3 | 小さいblue ● または blue数字 `1. 2.` | さらに細分・列挙 |

- **論理展開は `→`、結論・帰結は `⇒`**（矢印で流れを見せる）。
- 見出し語だけ太字にしてメリハリ（例：**Research Question**、**Data**、**Method**）。
- 数式内の変数はイタリック（`$X$`, `$Y_{jt}$`）。本文はサンセリフ（Noto Sans）で統一。
- 1つのL1配下は**2〜4項目**が目安。5項目を超えるならスライドを割る。
- **「Findings / Policy Implications」型のまとめスライド**を標準とする：
  「Findings」「Policy Implications」を別々のL1見出し（太字）にし、それぞれの下にL2で詳細を2〜3項目展開する
  （知見・含意がそれぞれ複数あることを前提にした型）。

---

## 4. 左右2カラム（`columns`）

- **左＝視覚物（図・表・数式・決定木）、右＝解釈の言葉**、を基本形にする。
- 右カラムは「読み解きの箇条書き」に徹する（結論・βの大小・メカニズム）。装飾しない。
- 図が主役のスライドは左右分割せず**中央1枚**で大きく見せてもよい（分布マップ等）。
- 2カラムは幅 `0.5 / 0.5` を基準。図が縦長なら `0.55 / 0.45` 程度まで。

---

## 5. 数式と変数定義ボックス

- **数式を上部**に置き、右端に式番号 `(1) (2) (3)`。
- その**変数定義だけ**を淡いblue地（`subblue`）の**ボックス（`defbox` 環境）で囲む**＝「定義ゾーン」を視覚的に隔離。
  - ボックス内は blue● `Outcome variable` / `Main explanatory variables` の見出し＋各変数の定義。
  - 定義文中のキーワードは `\textcolor{mainred}{...}` で強調。
  - 参照カテゴリなど重要な注記は `red` の1行で（例：「基準は導入の前年」）。
- **ボックスはこの「数式＋定義」用途に限定**。それ以外（普通の箇条書き）を囲まない。

---

## 6. 表（Table）

- **縦罫線なし・横罫線のみ**（`booktabs`：`\toprule` `\midrule` `\bottomrule`）。
- ラベル `Table X:` は **blue**（`\tlabel{Table 1:}`）、続く説明は黒。表の**上**に置く。
- **注目セルは `orange`** の背景（`\cellcolor{mainorange!25}`）または枠（`\ybox`）で強調。片側だけを目立たせる。
- **対比が必要な列/セル**は、注目したい方を `orange`、対になる文字は `blue`/`red` で色分け（枠の二色対比は使わない）。
- 表の下に、
  - `Note:` … 補足（`\slidenote{...}`：`textgray`・小さめ）
  - `*** p<0.01, ** p<0.05, * p<0.1` / 標準誤差の説明（詰めて書きたいときは `\tinynote{...}`）
- 幅が広い回帰表は**左右分割せず全幅**で置き、解釈は別スライド or 表の右に短く。
- **書き方の使い分け**：セル背景強調（`\cellcolor`）や特殊な装飾が必要な表は生LaTeX（`tabular`/`tabularx`+`booktabs`）で書く。
  強調不要な単なる説明用の表（データ一覧・変数一覧など）は、Markdownのパイプテーブルで手早く書いてよい
  （PandocのLaTeX出力も`booktabs`スタイルになるので「縦罫線なし」の見た目は崩れない。
  セル内に`\textcolor{mainred}{\textbf{...}}`等の生LaTeXを埋め込むことも可能）。
- 分析コードから表を出すときは、`tabular` だけの LaTeX 断片（booktabs）を書き出し、スライド側で
  `\begin{center}\small\input{…/table.tex}\end{center}` のように貼る。はみ出すときは `\footnotesize` と
  `\renewcommand{\arraystretch}{0.9}` で詰める。

## 7. 図（Figure）

- ラベル `Figure X:` は **blue**、図の**下**に置く。続けて `(source: ...)` を `textgray` 小さめで。
- 図は `keepaspectratio` で歪ませない。1枚に図は原則1〜2点。
- **図はスライドの実寸で作る**（拡大縮小すると文字の大きさが狂うため）：
  - 4:3 の本文の幅 ≈ **4.25 インチ**（用紙 128mm − 左右の余白）。図は幅 4.25 インチ・300dpi の PNG で作り、
    `\includegraphics[width=\linewidth]{…}` で等倍に貼る。
  - 高さの目安：タイトル＋リード1行＋図＋注2行を1枚に収めるなら **約 2.15 インチ**。
  - 文字：フォントはスライドと同じ Noto Sans JP、軸 8.5pt・凡例 9pt。
  - 図の中にタイトル・注は入れない（スライドのリード文と `Note:` 行に書く）。N は凡例かパネルの見出しに。
  - 群は色だけに頼らず形も変える（例：処置 = red ●、対照 = blue ▲）。
  - 新しい図は、テスト用のデッキで実寸に貼って、はみ出し・文字の大きさを目で確認してから本番に使う。
- 決定木・DAG は tikz（`box_node`=blue系／`key_node`=red系、`dag_node`/`arrow` スタイル）。
  - 通常ノードは blue 系、**結論となる1ノードだけ**を別色（`mainred` 系）で差別化。
- 図がまだ無いときは `\figplaceholder[幅]{ファイル名}` で仮置きする。

## 8. 引用・出典

- 本文引用は `(Author, Year)`、`textgray` の小さめ。強調しない。
- 参考文献は APA（`biblatex` + biber）。末尾に `allowframebreaks` の References スライド。
  - 本文中：`\textcite{key}` →「Author (Year)」、`\parencite{key}` →「(Author, Year)」。
  - `.bib` の題名の固有名詞は `{}` で囲む（APA は題名を小文字化するため。例：`{New Jersey}`）。
- 図表の出典は図表ラベル付近に簡潔に。
- **箇条書きの各項目が個別の文献に基づく場合**（例：複数の実証結果を1項目1本ずつ列挙する導入スライド）は、
  項目本文の直後に `\srcite{key}` を添えて、主張と出典を1対1で対応させる
  （`\srcite` = `\slidenote{\mbox{\parencite{key}}}`。(Author, Year) が途中で折り返さない。
  textgray/白のコントラスト比 約3.3:1とWCAG AA本文基準は下回るが、
  出典はリアルタイムで読ませる情報ではなく意図的な弱調子なので許容する）。

## 9. ナビゲーション・全体構成

- 上部に**セクション進行バー**（metropolis + `miniframes`）を常時表示。現在セクションは黒字、他はグレー、丸印で位置を示す。
- 右下にページ番号のみ。付録（`\appendix`）はページ番号から除外（`appendixnumberbeamer`）。
- 各セクションの冒頭に Outline（目次）を自動で入れる。現セクションを blue、他を淡色。
  - **短い発表（15〜20分）では YAML に `section-outline: false`** を書いて Outline を入れない。
    現在位置は上部のナビバーだけで示す。
- 付録へのジャンプは blue の**ボタン**（`\hyperlink{ラベル}{\beamerbutton{…}}`、飛び先に `\hypertarget{ラベル}{}`）。

## 10. やってはいけない（醜さ回避チェックリスト）

- [ ] 色を増やしすぎない（1枚で blue＋red＋（必要時）orange まで。新色を足さない）。
- [ ] ボックスを多用/入れ子にしない（ボックスは「数式＋定義」専用）。
- [ ] `orange` をテキスト色に使わない（背景/枠のみ。白背景コントラスト比が低く読みにくいため）。
- [ ] 文中 `red`/`blue` 強調が合計1枚に4語以上 → 強調が効かないので削る。
- [ ] 1枚に数式2本以上（IV例外を除く）→ スライドを割る。
- [ ] 箇条書きが4階層 → 3階層までに再構成。
- [ ] 図の歪み・出典漏れ・`Table/Figure` ラベル漏れ。
- [ ] リード文の無いスライド（各枚に主張を1行）。
- [ ] 余白ゼロの詰め込み → 情報を次スライドへ分割。
- [ ] `\alert` を使っている → `\textcolor{mainred}{...}` に置き換える。

## 11. 設計意図 → 実装 早見表

| 見た目 | 実装 |
|---|---|
| 上部ナビバー | `\useoutertheme[subsection=false]{miniframes}` |
| frametitle帯 | `\setbeamercolor{frametitle}{fg=textblack,bg=subblue}` |
| blue●箇条書き | `itemize`（記号色を mainblue に） |
| 文中強調（red/blue共通） | `\textcolor{mainred}{...}` / `\textcolor{mainblue}{...}`（太字併用は`\textcolor{mainred}{\textbf{...}}`） |
| 意見スライドの見出し強調 | `## \textcolor{mainred}{見出し}` |
| 変数定義ボックス | `defbox` 環境 |
| 表の注目セル | `\cellcolor{mainorange!25}...` |
| 短い語句の注目枠 | `\ybox{...}` |
| 複数行の要点強調 | `keytakeaway` 環境 |
| Table/Figureラベル blue | `\tlabel{Table X:}` |
| 図表の注 | `\slidenote{Note: ...}`（さらに小さく：`\tinynote{...}`） |
| 箇条書き項目の出典 | `\srcite{key}` |
| 図の仮置き | `\figplaceholder[幅]{ファイル名}` |
| 付録ボタン | `\hyperlink{...}{\beamerbutton{...}}` |
| 決定木/DAG | tikz（`box_node`=blue系／`key_node`=red系、`dag_node`/`arrow`） |
| Outline なし（短い発表） | YAML の `section-outline: false` |

> 本文は Markdown で書き、細かい枠・tikz・特殊配置は該当スライドだけ生LaTeXで記述する（ハイブリッド運用）。
